# Rename Files with Regex
This script changes filenames in bulk, located in a folder that is specified by the user via the prompt.

By default, file names are changed to small case letters.

There is a `test_folder` directory included, which can be used for development and experimentation.

To run:
1. Clone the folder to your harddrive.
2. In the folder where the files are cloned, type `python3 filename_rename_part.py`
3. Specify the absolute path of the directory in question.
4. Specify the regex pattern you want to use to find the part in the filenames that you want to change.
5. Specify the string that you want to replace the above given regex pattern with.
